# 💳 Wallet Management System

## 📌 Overview

The **Wallet Management System** is a Java Core project designed to simulate a simple digital wallet application.

The project focuses on applying Object-Oriented Programming (OOP) concepts, data validation, exception handling, and clean code organization through a practical implementation.

Users can create wallet accounts, manage their account information, and perform basic account management operations.

## 🚀 Features

- **Account Creation:** Create a new wallet account with personal information.
- **Account Validation:** Validate user information during account creation.
- **Account Authentication:** Find and authenticate accounts using username and password.
- **Password Management:** Change account passwords.
- **Account Status:** Manage account activation status.
- **Account Information:** Store username, password, phone number, balance, age, and account creation date.
- **Exception Handling:** Handle invalid inputs and account-related errors.
- **Account Management:** Organize and manage wallet accounts.

## 🏗️ Project Structure

The project is organized into separate classes to improve code readability and maintainability.

Main components include:

- **Account:** Represents a wallet account and its attributes.
- **AccountsBuilder:** Responsible for building and creating account objects.
- **Validation:** Handles input validation and ensures data integrity.
- **Exception Classes:** Handle specific errors and invalid operations.
